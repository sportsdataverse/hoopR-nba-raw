# Tracks sdv-py main: the stages import sportsdataverse.scrape.espn (the shared
# ESPN raw engine), which is on main and not yet in a PyPI release.
#
# A bare `>=` floor is not a pin on a host with a persistent site-packages --
# pip does not upgrade an already-satisfied requirement. `>=0.0.32` let
# wehoop-wnba-raw's runner sit on 0.0.50 for 25 releases and fail for three
# weeks. And for a git source, --upgrade is not enough either: pip decides
# satisfaction by VERSION, so a branch reporting an already-installed version
# is a silent no-op. Install with:
#   pip install --upgrade -r requirements.txt
#   pip install --force-reinstall --no-deps \
#     "sportsdataverse @ git+https://github.com/sportsdataverse/sportsdataverse-py@main"
